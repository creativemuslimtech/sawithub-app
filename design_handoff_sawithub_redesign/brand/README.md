# SawitHub Brand Assets

Identitas visual SawitHub. Semua file di folder ini tersedia untuk tim internal, koperasi mitra, dan media partner.

## Direktori
```
brand/
└── logo/
    ├── sawithub-horizontal.png       Logo utama PNG (304×110) — header, marketing
    ├── sawithub-horizontal.svg       Logo utama SVG — scalable, untuk web/print
    ├── sawithub-horizontal-mono.svg  Versi monokrom — pakai `currentColor`
    ├── sawithub-icon.png             Ikon kotak PNG (114×112) — favicon, social
    ├── sawithub-icon.svg             Ikon SVG transparan — untuk in-app
    ├── sawithub-icon-mono.svg        Ikon monokrom (currentColor)
    └── sawithub-app-icon-1024.svg    App icon 1024×1024 dengan cream rounded-square bg
```

## Spesifikasi warna
| Token        | Hex       | Pemakaian                                   |
| ------------ | --------- | ------------------------------------------- |
| Forest       | `#1A3D2B` | Logo stroke, `sawit` wordmark               |
| Forest-3     | `#2D5A3D` | `hub` italic                                |
| Amber        | `#D4A827` | Titik buah pada palm frond                  |
| Cream        | `#F5F0E8` | Background app icon, marketing surfaces     |

## Tipografi
- **Wordmark** — Fraunces, weight 500 (`sawit`) + italic weight 400 (`hub`)
- **Body** — DM Sans
- **Angka** — JetBrains Mono

## Aturan pemakaian
- Logo TIDAK boleh dimiringkan, di-outline, atau diisi warna selain forest.
- Ruang aman = tinggi huruf "s" pada wordmark, di semua sisi.
- Ukuran minimum digital: 88px lebar (horizontal), 24px (ikon).
- Ukuran minimum print: 18mm lebar (horizontal), 6mm (ikon).
- Jangan letakkan logo di atas latar yang kontrasnya < 4,5:1.

Untuk versi monokrom, gunakan SVG `-mono` yang otomatis mewarisi `currentColor`.
